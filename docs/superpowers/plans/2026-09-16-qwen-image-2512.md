# Qwen-Image-2512 Inference on torch-fl — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development
> (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `diffusers`' `QwenImagePipeline` produce a 1024x1024 PNG from a text prompt on the
`flagos` device of torch-fl, on three NVIDIA A100-40GB, and record what the backend needed in
order to get there.

**Architecture:** Bring the pipeline up one component at a time — text encoder, then a single
transformer step, then the VAE, then the full 50-step loop — so that a failure is attributable to
one component instead of to a two-forwards-per-step loop. The transformer is 40.4 GB of bf16
weights and does not fit on one 40 GB card, so it is split at a layer boundary across two `flagos`
devices with `accelerate.dispatch_model` and a hand-built device map. Correctness is established
by running the same script and the same injected inputs on a real CUDA PyTorch and comparing the
images with PSNR/MAE.

**Tech Stack:** torch_fl (`flagos` PrivateUse1 backend), PyTorch 2.10.0+cpu with an external CUDA
12.8 `libtorch_cuda.so`, diffusers 0.40.0, transformers 5.14.1, accelerate 1.14.0, 8x
NVIDIA A100-SXM4-40GB.

**Spec:** `docs/superpowers/specs/2026-09-16-qwen-image-2512-design.md`

> **Delivered layout differs from the paths below.** This plan was written for a flat
> `tests/manual/qwen_image_2512_*.py` naming and an A100-only three-card placement. What shipped is

| Fact | Value |
| --- | --- |

| Model snapshot | `Qwen/Qwen-Image-2512`, 54 GB, 30 files, in `$HF_HOME/hub` |
| Model layout | `text_encoder` 16.58 GB / 4 shards, `transformer` 40.4 GB / 9 shards, `vae` 254 MB |
| Pipeline class | `QwenImagePipeline` (`_class_name` in `model_index.json`) |
| `diffusers` latest on the index | 0.40.0 |
| `diffusers` is installed in | neither env yet |
| `pillow` is installed in | neither env yet |
| Latents are packed for the transformer | `prepare_latents` ends with `_pack_latents`, so what enters the denoising loop is `(1, 4096, 64)` for 1024x1024 — 64 = `in_channels`, 4096 = `(128/2)^2`. The 5-D `(1, 1, 16, 128, 128)` form only exists inside `prepare_latents`. |
| `latents=` injection bypasses packing | The `latents is not None` branch of `prepare_latents` returns the tensor as-is, moved to device and dtype. An injected tensor must therefore **already be packed**; the round trip works because `prepare_latents` returns the packed form on the generator branch, so saving its return value gives a re-injectable tensor. |
| `__call__` injectable inputs | `latents`, `prompt_embeds`, `prompt_embeds_mask`, `negative_prompt_embeds`, `negative_prompt_embeds_mask` |
| `encode_prompt` returns | `(prompt_embeds, prompt_embeds_mask)`, both sliced to `max_sequence_length` |
| `img_shapes` | `[[(1, height // vae_scale_factor // 2, width // vae_scale_factor // 2)]]` — note the two levels of nesting: one outer list per batch item, one tuple per frame. `[[(1, 64, 64)]]` at 1024x1024. |
| Transformer forward takes | `hidden_states, encoder_hidden_states, encoder_hidden_states_mask, timestep, img_shapes, guidance, attention_kwargs, controlnet_block_samples, additional_t_cond, return_dict`. There is **no** `txt_seq_lens` parameter — the model derives it from the mask. |
| `guidance_embeds` | `false` in the 2512 transformer config, and `guidance_scale` defaults to `None`, so `guidance` is `None` on every forward and `time_text_embed` is called with two arguments instead of three. |
| Decode path in `__call__` | `_unpack_latents` -> `to(vae.dtype)` -> `latents / latents_std + latents_mean` -> `vae.decode(...)[0][:, :, 0]`. The `latents_mean`/`latents_std` normalisation is done by the pipeline, not by the VAE, so anything decoding outside `__call__` must repeat it. |
| `prepare_latents` signature | `(batch_size, num_channels_latents, height, width, dtype, device, generator, latents=None)` |
| RoPE device handling | `QwenEmbedRope._get_device_freqs` does `self.pos_freqs.to(device)` explicitly; `ROPE_PER_DEVICE` has no `flagos` key, so `apply_rotary_emb_qwen(..., use_real=False)` is selected — complex dtype, `torch.view_as_complex` / `torch.view_as_real` |
| accelerate dispatch | `dispatch_model` attaches hooks when the device map spans >1 device; `hooks.py` moves weights with `module.to(execution_device)`. The only device read is `next(module.parameters()).device`. Not CUDA-specific. |
| `check_cuda_p2p_ib_support` | called only to emit a warning on multi-GPU; does not gate placement |

| CUDA assets for the build | `/nfs/lvyufeng/PyTorch-Plugin-FL/.libtorch_cuda_assets/` (1.15 GB, cu12.8) |
| CUDA toolkit on the host | `/usr/local/cuda` -> CUDA 13.0, `nvcc` present |

```python

"""Qwen-Image-2512 text-to-image inference on torch-fl, with a CUDA reference.

The ``--stage`` switch exists so that a failure is attributable to one
component. A full run is a 50-step denoising loop with two transformer forwards
per step; localising a crash inside that is far more expensive than localising
it in an isolated text-encoder call.

Stages:
    text-encoder      prompt -> prompt_embeds + prompt_embeds_mask
    transformer-step  one forward at fixed latents, true CFG disabled
    vae               decode fixed latents -> PNG
    full              the whole pipeline -> PNG

``torch_fl`` MUST be imported before ``torch``: it preloads the bundled
libtorch_cuda.so before PyTorch caches its CUDA hooks. The import is therefore
driven by ``--device`` after argument parsing and before anything else touches
torch.

Run on flagos (3 GPUs):
    python tests/manual/qwen_image_2512_infer.py --stage full \
        --prompt "a red panda eating bamboo" --output flagos.png

Run the CUDA reference with the same inputs:
    .../torch-cuda-210/bin/python tests/manual/qwen_image_2512_infer.py \
        --device cuda --stage full --load-inputs inp.pt \
        --load-latents lat.pt --output cuda.png
"""

import argparse
import sys

STAGES = ("text-encoder", "transformer-step", "vae", "full")

DEFAULT_PROMPT = "a red panda eating bamboo, soft morning light, photorealistic"


def parse_args(argv=None):
    parser = argparse.ArgumentParser(
        description="Qwen-Image-2512 inference on flagos or cuda",
        formatter_class=argparse.ArgumentDefaultsHelpFormatter,
    )
    parser.add_argument("--stage", choices=STAGES, default="full")
    parser.add_argument(
        "--device",
        default="flagos",
        choices=("flagos", "cuda"),
        help="device family; selects whether torch_fl is imported first",
    )
    parser.add_argument("--model", default="Qwen/Qwen-Image-2512")
    parser.add_argument("--prompt", default=DEFAULT_PROMPT)
    parser.add_argument(
        "--negative-prompt",
        default=" ",
        help="an empty value disables true CFG, which visibly degrades the image",
    )
    parser.add_argument("--seed", type=int, default=0)
    parser.add_argument("--steps", type=int, default=50)
    parser.add_argument("--height", type=int, default=1024)
    parser.add_argument("--width", type=int, default=1024)
    parser.add_argument("--max-sequence-length", type=int, default=512)
    parser.add_argument(
        "--encoder-device",
        default=None,
        help="default: <device>:2, so the text encoder can be released before denoising",
    )
    parser.add_argument(
        "--transformer-devices",
        nargs="+",
        default=None,
        help="default: <device>:0 <device>:1 — the transformer does not fit on one 40GB card",
    )
    parser.add_argument("--vae-device", default=None, help="default: <device>:0")
    parser.add_argument(
        "--split-at",
        type=int,
        default=30,
        help="transformer_blocks [0, split_at) go to the first transformer device",
    )
    parser.add_argument("--output", default=None, help="PNG path")
    parser.add_argument(
        "--save-inputs",
        default=None,
        help="write prompt embeds, mask, and the negative pair to this .pt",
    )
    parser.add_argument("--load-inputs", default=None)
    parser.add_argument("--save-latents", default=None, help="write the initial latents to this .pt")
    parser.add_argument("--load-latents", default=None)
    return parser.parse_args(argv)


def import_torch(device_kind):
    """Import torch_fl first when running on flagos, then return torch."""
    if device_kind == "flagos":
        import torch_fl  # noqa: F401  - must precede `import torch`
    import torch

    return torch


def device_strings(args):
    """Resolve the three placement strings, defaulting per the spec's layout."""
    base = args.device
    encoder = args.encoder_device or f"{base}:2"
    transformer = list(args.transformer_devices or [f"{base}:0", f"{base}:1"])
    vae = args.vae_device or f"{base}:0"
    return encoder, transformer, vae


def load_pipeline(torch, args):
    from diffusers import QwenImagePipeline

    pipe = QwenImagePipeline.from_pretrained(args.model, dtype=torch.bfloat16)
    return pipe


def split_transformer(torch, transformer, devices, split_at):
    """Place the transformer across `devices`, splitting between blocks."""
    from accelerate import dispatch_model

    blocks = list(transformer.transformer_blocks)
    if split_at <= 0 or split_at >= len(blocks):
        raise ValueError(f"--split-at must be in 1..{len(blocks) - 1}, got {split_at}")
    if len(devices) != 2:
        raise ValueError(f"expected 2 transformer devices, got {len(devices)}")

    # Enumerate the top-level children rather than naming them. dispatch_model's
    # first statement is check_device_map, which raises on any parameter the map
    # does not cover -- and a hardcoded name list that drifts from the model
    # fails as an opaque "does not give any device for the following parameters".
    # named_children() is exhaustive by construction, so nothing can be missed.
    device_map = {}
    for name, _ in transformer.named_children():
        if name != "transformer_blocks":
            device_map[name] = devices[0]
    for i in range(len(blocks)):
        device_map[f"transformer_blocks.{i}"] = devices[0] if i < split_at else devices[1]
    # These run after the last block, so they belong with the second shard.
    for name in ("norm_out", "proj_out"):
        if name in device_map:
            device_map[name] = devices[-1]

    print(f"  transformer: blocks 0..{split_at - 1} -> {devices[0]}, "
          f"{split_at}..{len(blocks) - 1} -> {devices[1]}")
    return dispatch_model(transformer, device_map=device_map)


def place_pipeline(torch, pipe, args):
    """Move the components this stage needs. The transformer is 40 GB, so stages
    that never call it must not pay for loading it onto the GPUs."""
    encoder, transformer, vae = device_strings(args)

    if args.stage in ("text-encoder", "vae"):
        if args.stage == "vae":
            pipe.vae.to(torch.device(vae))
            print(f"  vae          -> {vae}")
        else:
            pipe.text_encoder.to(torch.device(encoder))
            print(f"  text_encoder -> {encoder}")
        return None

    if args.stage in ("transformer-step", "full"):
        pipe.text_encoder.to(torch.device(encoder))
        print(f"  text_encoder -> {encoder}")
    if args.stage == "full":
        pipe.vae.to(torch.device(vae))
        print(f"  vae          -> {vae}")

    return split_transformer(
        torch, pipe.transformer, [torch.device(d) for d in transformer], args.split_at
    )


def stage_text_encoder(torch, pipe, args):
    """Encode the prompt, and the negative prompt when true CFG is enabled.

    Both are saved together: the paired comparison must inject the negative
    embeddings too, otherwise the reference run would recompute them on its own
    backend and the comparison would no longer isolate the denoising loop.
    """
    encoder = torch.device(device_strings(args)[0])
    pipe.text_encoder.to(encoder)

    with torch.no_grad():
        prompt_embeds, prompt_embeds_mask = pipe.encode_prompt(
            prompt=args.prompt,
            device=encoder,
            num_images_per_prompt=1,
            max_sequence_length=args.max_sequence_length,
        )
        negative_embeds = negative_mask = None
        if args.negative_prompt:
            negative_embeds, negative_mask = pipe.encode_prompt(
                prompt=args.negative_prompt,
                device=encoder,
                num_images_per_prompt=1,
                max_sequence_length=args.max_sequence_length,
            )
```

```python
def make_latents(torch, pipe, args, device):
    """Build the packed initial latents exactly as QwenImagePipeline.__call__ does.

    ``prepare_latents`` packs on its generator branch but returns an injected
    tensor untouched, so both branches end up handing back the packed
    ``(batch, num_patches, in_channels)`` form. Saving the return value of the
    generator branch therefore produces a tensor the other backend can inject.
    """
    generator = torch.Generator(device=device).manual_seed(args.seed)
    loaded = None
    if args.load_latents:
        loaded = torch.load(args.load_latents, map_location="cpu")
        print(f"  loaded latents <- {args.load_latents} {tuple(loaded.shape)}")

    latents = pipe.prepare_latents(
        1,
        pipe.transformer.config.in_channels // 4,
        args.height,
        args.width,
        pipe.transformer.dtype,
        device,
        generator,
        latents=loaded,
    )
    print(f"  latents {tuple(latents.shape)} {latents.dtype} {latents.device}")
    if args.save_latents:
        torch.save(latents.detach().cpu(), args.save_latents)
        print(f"  saved latents -> {args.save_latents}")
    return latents


def stage_transformer_step(torch, pipe, args):
    """One denoising forward at fixed latents, with true CFG disabled."""
    _, transformer_devices, _ = device_strings(args)
    latent_device = torch.device(transformer_devices[0])

    prompt_embeds, prompt_embeds_mask, _, _ = _prompt_inputs(torch, pipe, args)
    latents = make_latents(torch, pipe, args, latent_device)

    # encode_prompt only moves embeddings on the path that computes them, and
    # the text encoder lives on a different device than the first transformer
    # shard. Nothing downstream will do this for us.
    prompt_embeds = prompt_embeds.to(latent_device)
    if prompt_embeds_mask is not None:
        prompt_embeds_mask = prompt_embeds_mask.to(latent_device)

    # The scheduler turns a sigma into the timestep the transformer is called with.
    pipe.scheduler.set_timesteps(args.steps, device=torch.device("cpu"))
    timestep = pipe.scheduler.timesteps[0].expand(latents.shape[0]).to(latents.dtype)

    img_shapes = [
        [(1, args.height // pipe.vae_scale_factor // 2, args.width // pipe.vae_scale_factor // 2)]
    ]

    with torch.no_grad():
        noise = pipe.transformer(
            hidden_states=latents.to(pipe.transformer.dtype),
            timestep=timestep / 1000,
            encoder_hidden_states=prompt_embeds,
            encoder_hidden_states_mask=prompt_embeds_mask,
            img_shapes=img_shapes,
            return_dict=False,
        )[0]

    print(f"  transformer noise {tuple(noise.shape)} {noise.dtype} {noise.device}")
    expected = torch.device(transformer_devices[-1])
    print("  device check   :", "OK" if noise.device == expected else f"FAIL (expected {expected})")
    return noise
```

Three details in the call above are copied from `pipeline_qwenimage.py`'s `__call__` rather than
invented, and are exactly where a hand-written loop goes wrong:

- **`img_shapes` has two levels of nesting** — `[[(1, 64, 64)]]`, a list per batch item
  containing a tuple per frame. A flat `[(1, 64, 64)]` reaches `pos_embed` as the wrong structure.
- **No `txt_seq_lens`** — the model has no such parameter; it derives the length from
  `encoder_hidden_states_mask` internally.
- **No `guidance`** — `guidance_embeds` is `false` in the 2512 transformer config, so the field
  stays `None` and `time_text_embed` takes the two-argument path.

Also add the shared prompt-input helper. It wraps `stage_text_encoder` rather than replacing it, so
the text-encoder stage from Task 2 stays usable on its own, and the stages that need embeddings on
the transformer's device get the injectable form:

```python
    if path is None:

def stage_vae(torch, pipe, args):
    """Decode latents through the causal Conv3d VAE and write a PNG."""
    _, _, vae_device = device_strings(args)
    vae_dev = torch.device(vae_device)
    pipe.vae.to(vae_dev)

    latents = make_latents(torch, pipe, args, vae_dev)

    # Copied from QwenImagePipeline.__call__'s decode path. The pipeline
    # normalises with the VAE's own latents_mean / latents_std before calling
    # decode, so a decoder driven outside __call__ has to repeat it.
    with torch.no_grad():
        latents = pipe._unpack_latents(latents, args.height, args.width, pipe.vae_scale_factor)
        latents = latents.to(pipe.vae.dtype)
        z_dim = pipe.vae.config.z_dim
        latents_mean = torch.tensor(pipe.vae.config.latents_mean).view(1, z_dim, 1, 1, 1)
        latents_std = 1.0 / torch.tensor(pipe.vae.config.latents_std).view(1, z_dim, 1, 1, 1)
        latents = latents / latents_std.to(latents.device, latents.dtype)
        latents = latents + latents_mean.to(latents.device, latents.dtype)
        print(f"  unpacked {tuple(latents.shape)} {latents.dtype} {latents.device}")

        image = pipe.vae.decode(latents, return_dict=False)[0][:, :, 0]
    print(f"  decoded {tuple(image.shape)} {image.dtype} {image.device}")

    images = pipe.image_processor.postprocess(image, output_type="pil")
    save_images(images, args.output)
    return images
```

that drops the frame axis. There is no `scaling_factor` division; this VAE normalises through its
`latents_mean` / `latents_std` instead, and that normalisation happens in the pipeline, not in
`decode`. Verify against the installed source before running.

```python
def stage_full(torch, pipe, args):
    """The whole pipeline: prompt -> prompt embeds -> latents -> denoise -> decode."""
    _, transformer_devices, _ = device_strings(args)
    latent_device = torch.device(transformer_devices[0])

    prompt_embeds, prompt_embeds_mask, negative_embeds, negative_mask = _prompt_inputs(
        torch, pipe, args
    )

    latents = make_latents(torch, pipe, args, latent_device)
    generator = torch.Generator(device=latent_device).manual_seed(args.seed)

    prompt_embeds = prompt_embeds.to(latent_device)
    if prompt_embeds_mask is not None:
        prompt_embeds_mask = prompt_embeds_mask.to(latent_device)
    if negative_embeds is not None:
        negative_embeds = negative_embeds.to(latent_device)
        negative_mask = negative_mask.to(latent_device)

    with torch.no_grad():
        result = pipe(
            prompt=None,
            negative_prompt=None,
            prompt_embeds=prompt_embeds,
            prompt_embeds_mask=prompt_embeds_mask,
            negative_prompt_embeds=negative_embeds,
            negative_prompt_embeds_mask=negative_mask,
            true_cfg_scale=4.0 if negative_embeds is not None else 1.0,
            latents=latents,
            num_inference_steps=args.steps,
            height=args.height,
            width=args.width,
            max_sequence_length=args.max_sequence_length,
            generator=generator,
            output_type="pil",
        )

    save_images(result.images, args.output)
    return result.images
```

Passing `prompt=None` with explicit `prompt_embeds` keeps the text encoder out of the call — this is
the supported diffusers path, not a workaround: `encode_prompt` short-circuits and `check_inputs`
accepts the pair. It means the embeddings that go into denoising are exactly the ones the
comparison injects.

`pipe` is also handed the injected `latents`, which the pipeline forwards straight into
`prepare_latents`. As noted in the constraints, that branch does not re-pack, so what is injected
must already be packed — which is what `make_latents` saved.

```python
"""Compare two images produced by qwen_image_2512_infer.py.

PSNR and mean absolute error, in 8-bit units. Bitwise equality is not a
meaningful target: bf16 accumulation order differs between backends, and the
error compounds over 50 steps of iterative refinement.

Run:
    python tests/manual/qwen_image_2512_compare.py --a flagos.png --b cuda.png

import argparse
import sys

import numpy as np
from PIL import Image


def parse_args(argv=None):
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("--a", required=True)
    parser.add_argument("--b", required=True)
    return parser.parse_args(argv)


def load(path):
    with Image.open(path) as handle:
        return np.asarray(handle.convert("RGB"), dtype=np.float64)


def main(argv=None):
    args = parse_args(argv)
    a = load(args.a)
    b = load(args.b)

    if a.shape != b.shape:
        print(f"FAIL: shape mismatch {a.shape} vs {b.shape}")
        return 1

    diff = np.abs(a - b)
    mae = float(diff.mean())
    mse = float((diff**2).mean())
    if mse == 0.0:
        psnr = float("inf")
    else:
        psnr = float(10.0 * np.log10((255.0**2) / mse))

    print(f"a    : {args.a}")
    print(f"b    : {args.b}")
    print(f"shape: {a.shape}")
    print(f"MAE  : {mae:.4f}")
    print(f"PSNR : {psnr:.2f} dB")
    print(f"max  : {diff.max():.1f}")
    return 0


if __name__ == "__main__":
    sys.exit(main())
```
